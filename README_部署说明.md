# 公共网页部署说明

这是一个纯静态网站，不依赖 Python 或数据库服务。包含 61 个 HTML 页面、58 组图文详情和本地数据图表。

本地测试可直接双击 `index.html`；公网访问则需要先完成下面的静态托管发布。发布后会得到一个可在电脑和手机浏览器中打开的 HTTPS 链接。

## 部署后的访问方式

部署完成后会得到一个 HTTPS 公网链接。电脑、平板和手机都可以直接打开，不需要安装软件，也不需要数据库账号。

## 方案 A：Netlify Drop

1. 登录 Netlify。
2. 打开 Netlify Drop。
3. 把当前文件夹压缩后上传，或直接拖入整个文件夹。
4. 等待生成 `*.netlify.app` 公网链接。
5. 可在 Netlify 后台绑定自己的域名。

## 方案 B：Cloudflare Pages

1. 登录 Cloudflare。
2. 进入 Workers & Pages，创建 Pages 项目。
3. 选择直接上传静态资源。
4. 上传本文件夹，无需设置构建命令。
5. 发布后会得到 `*.pages.dev` 地址。

## 方案 C：GitHub Pages

1. 新建公开 GitHub 仓库。
2. 将本文件夹内容提交到仓库根目录。
3. 在 Settings → Pages 中选择 `Deploy from a branch`。
4. 选择 `main` 分支和根目录，保存后等待发布。

## 注意事项

- 必须上传整个文件夹，不能只上传 `index.html`。
- 当前页面已启用移动端视口、响应式布局、触控导航和本地 WebP 图片；无需额外开发手机版。
- 不建议把本地绝对路径写入公网页面。
- 中国大陆访问速度受托管服务线路影响；如需面向大陆用户提供稳定速度，可选择阿里云 OSS、腾讯云 COS 或国内静态托管，并按要求完成域名与备案。
- 发布前应确定数据是否允许公开传播；当前包只包含用户提供的拍卖资料，不代表已获得第三方内容的再发布授权。
